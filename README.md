## Practice Database

E-commerce schema: `customers`, `orders`, `order_items`, `products`, `categories`.

**Spin up:**
```bash
docker run --name sql-practice \
  -e MYSQL_ROOT_PASSWORD=practice \
  -e MYSQL_DATABASE=learning \
  -p 3306:3306 \
  -d mysql:8.0
```

**Load schema + seed data:**
```bash
docker exec -i sql-practice mysql -u root -ppractice learning < schema/setup.sql
```

**Connect:**
```bash
docker exec -it sql-practice mysql -u root -ppractice learning
```

## How This Repo Works

- `notebooks/` — one notebook per phase; each cell is a query + its live output saved inline
- `exams/` — exam files generated by Claude scanning the notebooks
- `schema/setup.sql` — the practice database

**To generate a quiz:** tell Claude to scan the notebooks and generate an exam in the style of `exams/exam-1.md`.
